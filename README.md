# 真空上料机 3D 动态仿真

基于 **Three.js 原生能力**实现的真空上料机（负压气力输送）原理可视化演示。
无重型物理 / 流体求解库，粒子仅用于表现粉体输送走向，纯视觉示意。

## 快速运行

```bash
node server.mjs
# 浏览器打开 http://localhost:8080
```

> 必须通过 HTTP 访问（ES Module 与 GLTFLoader 在 `file://` 下会被 CORS 拦截）。
> 除 Three.js 通过 CDN 引入外无其他依赖，`server.mjs` 与模型生成器均为零依赖 Node 脚本。

## 工作流程演示

风机抽气在主机仓内形成 **负压** → 取料仓底部粉体被吸入输送管道 →
沿管路进入主机仓 → 粉体失速 **沉降** 至锥底料堆、气体穿过滤筒 →
洁净空气经风机从排气口 **排出**，完成气料分离。

- 暖色（驼色）粒子 = 粉体物料，在取料口持续生成、沿负压气流移动、仓内下沉堆积
- 冷色（浅蓝）粒子 = 空气，穿过滤筒后从排气口向外扩散消散
- 主机罐体半透明，可直接观察内部滤筒与粉体沉降过程

## 交互与控件

| 操作 | 方式 |
| --- | --- |
| 旋转视角 | 鼠标左键拖拽 |
| 缩放 | 滚轮 |
| 平移 | 鼠标右键拖拽 |
| 启停 / 暂停定格 | 左上角「暂停 / 启动」按钮 |
| 重置粒子 | 「重置粒子」按钮（清空料堆与管路粒子后重新生成） |
| 输送风速 | 滑块 0.6 ~ 3.2 m/s，粒子移动速度与生成速率同步联动 |

暂停后动画完全冻结，可定格观察粉体在管路内的瞬时流动状态；风机叶轮同步停转。

## 目录结构

```
.
├── index.html              页面外壳 + 极简控件 UI + importmap
├── js/
│   └── main.js             仿真主程序（场景/装配/粒子系统/动画状态机/UI 联动）
├── models/                 5 个轻量化 GLB 模型（总顶点约 4000，单文件 15~56KB）
│   ├── hopper.glb          取料仓（料斗 + 支腿 + 吸料嘴）
│   ├── pipes.glb           管路套件（直管 / 90° 弯头 / 法兰）
│   ├── chamber.glb         主机（半透明罐体 + 锥底 + 支腿 + 接口 + 卸料阀）
│   ├── filter.glb          滤筒（滤芯 + 端盖 + 吊杆）
│   └── fan_base.glb        风机底座（底座 + 电机 + 蜗壳 + 可旋转叶轮 impeller）
├── tools/
│   ├── make-glb.mjs        零依赖 glTF/GLB 程序化生成器（node tools/make-glb.mjs）
│   ├── cdp-check.mjs       无头浏览器交互/状态自动化回归
│   ├── shots.mjs           多视角截图核对
│   └── glb-debug.html      GLTFLoader 加载专项调试页
└── server.mjs              零依赖静态文件服务器
```

## 技术要点

- **GLTFLoader** 加载本地 GLB；任一模型加载失败时自动用同布局程序化几何体兜底，页面始终可运行
- **OrbitControls** 处理全部相机交互，带阻尼
- **requestAnimationFrame** 驱动动画循环，`delta` 限幅防止切后台后跳变
- 粒子为两套 `THREE.Points` + 自定义 `ShaderMaterial`（软圆形片元），
  CPU 每帧仅更新 position / alpha 缓冲，无碰撞计算，1500+ 粒子仍流畅
- 粉体沿 `CatmullRomCurve3` 管路曲线运动，状态机 `travel → settle → settled`，
  沉降槽位严格约束在锥体内腔，避免穿模
- 环境光 + 带柔和阴影的方向光（PCFSoftShadowMap）+ 淡雾效，场景仅保留设备主体与基座

## 重新生成模型

```bash
node tools/make-glb.mjs
```

模型由 `tools/make-glb.mjs` 以纯 Node（无第三方库）手写 glTF 2.0 二进制结构生成，
修改尺寸 / 材质 / 部件后重跑此命令即可刷新 `models/` 下全部 GLB。

## 说明

本项目仅做工艺原理的视觉示意，**不做真实负压、压力损失、气固两相流计算**，
粒子不参与精细碰撞，UI 仅保留必要控件，不堆砌数据面板。
